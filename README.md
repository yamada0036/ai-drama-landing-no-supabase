# AI Drama Ads — Vercel MVP

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to GitHub, or import it directly in Vercel.
2. Framework preset: Next.js.
3. Build command: `next build` (default).
4. Deploy.

## Before public launch
- Replace `https://ai-drama-ads.vercel.app` in `app/layout.js`, `app/sitemap.js`, and `app/robots.js` with your final Vercel or custom domain.
- Replace `hello@example.com` in `app/contact/page.js` with your real email or a form provider endpoint.
- Replace the placeholder cards on `/examples` with your actual vertical drama videos.
- Add your Instagram, YouTube, X and LinkedIn links in the footer.
- After a custom domain is connected, add the property in Google Search Console and submit `/sitemap.xml`.
